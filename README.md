# Selenium Automation Practice

A beginner-level Selenium WebDriver project created using JavaScript and Node.js.

## Completed Work

- Automated Google Chrome using Selenium WebDriver
- Opened and navigated websites automatically
- Located elements using CSS selectors, XPath and IDs
- Automated form login with username and password
- Added explicit waits for webpage elements
- Captured screenshots for successful and failed login tests
- Scraped book titles and prices from two webpages
- Saved the scraped data in a CSV file

## Technologies

- JavaScript
- Node.js
- Selenium WebDriver
- Google Chrome

## Installation

```bash
npm install
```

## Run Scripts

```bash
node selenium.js
node form.js
node scraping.js
```

The scraped book information is saved in `books.csv`.
